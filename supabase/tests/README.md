# Database checks

`rls_check.sql` asserts the access model in `0001_init.sql`: teachers see only their own questions,
masters never see who tried their advice, master credit honours each master's `show_name`, a thank
you reaches only the master whose card helped, reviewers see redacted question text but never a
teacher's id, voice or profile, officers get aggregates only, anon gets library counts only, and an
approved card must cite the recording.

CI runs it on every push (job `db`, Postgres 17). Locally, against a throwaway Postgres (14+), never
the hosted project: `DB_CHECK_URL=postgresql://localhost/parampara_rls pnpm db:check`, or by hand:

```bash
createdb parampara_rls
psql -d parampara_rls -v ON_ERROR_STOP=1 -f supabase/tests/supabase_shim.sql
psql -d parampara_rls -v ON_ERROR_STOP=1 -f supabase/migrations/0001_init.sql
psql -d parampara_rls -v ON_ERROR_STOP=1 -f supabase/tests/rls_check.sql   # ends with "All RLS checks passed."
dropdb parampara_rls
```

Last local run: 28 Oct 2026, Postgres 14, 0001 to 0007, 136 checks passed (adds 0007: a group QR mints one
person's link per scan and never passes its limit, is closed by expiry or revoking, is teachers only, and
`join_group_invite` is service role only; feedback names a role, never a person, and quoting is off unless
she ticks it. A race of 12 parallel scans on a 3 place group, run by hand, let exactly 3 in).
Earlier run: 24 Oct 2026, Postgres 14, 0001 to 0006, 122 checks passed (adds 0006: insights for
officers and reviewers only, groups under 5 teachers suppressed and shielded from differencing, field and
Sample apart, no teacher column in any insights function, the digest cache and open cards server only, words only).

## The Sample world (D88)

`sample_world_check.sql` writes a small field test, takes every field number the app shows (/how's
field totals, the field library count, the officer's field Pulse, Lamps and practices, a field
master's room, open data), writes the whole Sample world beside it (seed:demo's accounts,
seed:library, seed:pulse, generated by `scripts/sample-world-sql.mjs` from the same plan, no keys),
and checks that every field number is unchanged and that the Sample Pulse, Lamps and the demo
master's room light up. On a throwaway database with the shim and 0001 to 0006 applied:

```bash
node scripts/sample-world-sql.mjs > /tmp/world.sql          # optional: an ISO time as the run time
psql -d parampara_rls -v seed=/tmp/world.sql -f supabase/tests/sample_world_check.sql
# ends with "All Sample world checks passed."
```

Last local run: 28 Oct 2026, Postgres 14, 0001 to 0006, run times 28 Oct, 30 Oct, 1 Nov and 18 Nov:
16 checks passed each time.
